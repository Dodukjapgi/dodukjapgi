# 도둑잡기 (Dodukjapgi)

Java 콘솔 기반의 2~3인용 **도둑잡기** 카드 게임입니다. 한 대의 컴퓨터에서 번갈아 가며 즐기는 핫시트 (hot-seat) 방식이며, 마지막까지 조커를 들고 있는 사람이 패배합니다.

## 주요 기능

- 회원 등록 (이름, 나이) 및 마이페이지 (누적 점수, 참가자별 점수 확인)
- 2~3명 참가 지원
- 일반 카드 52장 + 조커 1장 덱 자동 생성, 셔플, 분배
- 같은 숫자 카드 자동 짝 제거
- 본인 차례에만 카드 공개 (엔터 입력 후 확인, 턴 종료 시 화면 비우기)
- 승리자 500점 지급, 재대결 지원

## 게임 규칙

1. 일반 카드 52장과 조커 1장을 사용합니다.
2. 카드를 모든 참가자에게 한 장씩 돌아가며 나눠 주고, 같은 숫자의 카드 두 장은 짝으로 버립니다.
3. 자신의 차례에 다음 순서 참가자의 카드 중 한 장을 번호로 골라 가져옵니다.
4. 가져온 카드와 같은 숫자가 손에 있으면 짝으로 버립니다.
5. 마지막에 조커 한 장만 남은 참가자가 패배하고, 나머지는 승리하여 500점을 얻습니다.

## 요구 사항

- JDK 8 이상 (IntelliJ IDEA 프로젝트 구조 사용)
- 이모지 (♠️♥️♣️♦️) 출력을 지원하는 UTF-8 터미널

## 실행 방법

### IntelliJ IDEA

`dodukjapgi/src/com/run/Application.java`의 `main`을 실행합니다.

### 터미널

```bash
cd dodukjapgi
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -Dfile.encoding=UTF-8 -cp out com.run.Application
```

## 사용 방법

1. 실행 후 이름과 나이를 입력해 회원 등록을 합니다.
2. 메인 메뉴에서 번호를 선택합니다.

   | 번호 | 메뉴 |
      | --- | --- |
   | 1 | 게임시작 |
   | 2 | 마이페이지 |
   | 3 | 규칙 |
   | 0 | 종료 |

3. 게임 시작 시 참가 인원 (2~3명)과 참가자 이름을 입력합니다.
4. 각자 차례에 엔터를 눌러 자신의 카드를 확인하고, 상대 카드 번호를 선택해 뽑습니다.
5. 게임이 끝나면 결과가 출력되며, 한 판 더 할지 선택할 수 있습니다.

## 프로젝트 구조

```
dodukjapgi/src/com
├── run/Application.java   # 진입점
├── GameMenu.java          # 메뉴, 회원 등록, 참가자 생성, 재대결 처리
├── Game.java              # 덱 생성/분배, 턴 진행, 짝 제거, 결과 출력
├── GameRules.java         # 게임 규칙 인터페이스
├── ThiefGameRules.java    # 도둑잡기 규칙 구현 (짝 판정, 종료/패배 판정)
├── Card.java              # 카드 추상 클래스
├── NormalCard.java        # 일반 카드 (숫자 + 무늬)
├── JokerCard.java         # 조커 카드
├── Player.java            # 참가자 추상 클래스 (패, 점수 관리)
├── Player1~3.java         # 참가자 1~3
└── dto/MemberDTO.java     # 회원 정보 (이름, 나이, 누적 점수)
```

`GameRules` 인터페이스로 규칙을 분리해 두어, 다른 카드 게임 규칙으로 확장하기 쉬운 구조입니다.
